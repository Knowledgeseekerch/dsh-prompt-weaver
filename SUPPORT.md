# Support

Before opening an issue:

1. Run the offline commands:
   ```bash
   npm run check
   npm run lint
   npm test
   npm run cli:smoke
   ```
2. Try a small prompt with no project context.
3. For DSH-only problems, use the **Compatibility report** template and include the exact DSH version and redacted RPC result.
4. For security vulnerabilities, follow `SECURITY.md`; do not open a public issue.

Questions about model quality are best framed with the exact draft structure, expected constraints, and the quality-gate result. Do not paste private project content or credentials.
